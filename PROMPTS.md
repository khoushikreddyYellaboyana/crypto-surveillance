AI Prompts Used
I used an AI assistant to help write the code and documentation for this project. These are the main prompts I used:

Prompt 1 – Create the project
Build a real-time crypto market surveillance project using Apache Kafka. Use live data from public sources like https://github.com/conduktor/public-streaming-api. Include throughput, latency, scalability, reliability, and accuracy, and add a simple README file.

Prompt 2 – Run the project
Show me how to set up and run this project step by step on my laptop using Docker.

Prompt 3 – Understand the code
Explain how the data flows from the exchanges to the dashboard, and briefly explain what each file in the project does.

Prompt 4 – Add features after review
Update the project to include these three things:

Clearer business alerts on the dashboard

Data recovery if the app crashes

A way to stop duplicate trades if the producer sends data twice

Prompt 5 – Fix dashboard bugs
Fix the red error message showing on the dashboard, and stop the page from jumping when I hover my mouse over the graph.
